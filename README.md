# ask-devenv

Local development environment for the Ask AI assistant ecosystem.

Assembles the following repos and starts them with docker-compose:

- [ask-backend](https://github.com/Weezevent/ask-backend)
- [ask-frontend](https://github.com/Weezevent/ask-frontend)

## Prerequisites

- Docker + Docker Compose
- mkcert (HTTPS)
